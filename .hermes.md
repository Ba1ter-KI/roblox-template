# Roblox Spiel-Repo (aus roblox-template)

Regeln für Agent-Sessions in diesem Repo. Wird von Hermes in jeder Session hier automatisch geladen.

## Stack
- Luau (Roblox), Rojo 7.x für Datei↔Studio-Sync
- Struktur: `src/server/` (Server), `src/client/` (Client), `src/shared/` (beide Seiten)

## Code-Konventionen
- Server-Autorität: Spiellogik läuft serverseitig; Client nur UI/Input/Prediction
- Module für wiederverwendbaren Code, keine globalen Variablen
- `--!strict` Typisierung in shared/server-Modulen wo möglich
- Neue Instanzen/Dateien IMMER in `src/` anlegen (Rojo-synced), nie manuell in Studio
- RemoteEvents/Functions zentral in `src/shared/network` definieren
- Balance-Werte (Preise, Timings, Rates) zentral in `src/shared/config`, nie verstreut im Code

## Workflow
- Agent schreibt/ändert Code und startet `rojo serve` auf Jarvis (bindet an Tailscale-IP via serveAddress) → Cedrik verbindet das Studio-Plugin (100.73.124.78:34872) und testet → Feedback → Iteration
- Vor "fertig": Syntax-Check (luau/selene, falls installiert), keine TODOs im committed Code
- Commits: `feat:`, `fix:`, `chore:`, `docs:` Konvention

## Launch-Richtlinie (projekt-übergreifend, 2026-10-27 entschieden)
- Softlaunch nach 4–6 Wochen Entwicklung
- Danach wöchentliche Update-Kadenz, datengetrieben (Retention: D1/D7, Session-Länge)
